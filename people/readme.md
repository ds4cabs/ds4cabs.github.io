# DS4CABS People Profiles

Each HTML file in this directory is a standalone profile page. After changes are published to the `ds4cabs.github.io` repository, a profile can be viewed directly at:

```text
https://ds4cabs.github.io/people/<profile-file>.html
```

For example: <https://ds4cabs.github.io/people/shicheng-guo.html>

## Preview locally

From the repository root, start a local web server:

```bash
python3 -m http.server 8000
```

Then open a profile at:

```text
http://localhost:8000/people/<profile-file>.html
```

Example: <http://localhost:8000/people/shicheng-guo.html>

> Keep this table updated whenever a profile HTML file is added, renamed, or removed.
